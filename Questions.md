# Questions

The Claude manager writes this file. No other agent edits it. After Codex merges the
plans, the manager copies every question from the merged plan here.

- **Resolved**: answered from the project files. The Basis column names the file and
  section that supports the answer.
- **Escalated**: nothing in the project files supports an answer. The user decides at
  the approval gate. Escalated questions are written in plain language.

Question IDs look like `P<phase>-Q-<CLA|CDX>-<number>`.
